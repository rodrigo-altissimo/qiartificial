# Enrichment: Lean Software Development & Mob Architecture
**Target Agent:** `@eng-agile`
**Key Concepts to Integrate into Agent's DNA:**

## 1. Lean Software Development
- **Core Principles:** Eliminate waste, build quality in, create knowledge, defer commitment, deliver fast, respect people, optimize the whole.
- **Waste in Software:** Partially done work, extra features (YAGNI), relearning, handoffs between teams, delays, task switching, and defects.
- **Build Quality In:** Don't test to find bugs; test to prevent bugs. This aligns perfectly with Red-Green-Refactor (TDD/BDD).
- **Defer Commitment:** Delay permanent decisions as long as possible (until the "Last Responsible Moment") to gather the maximum amount of contextual information before hardcoding it.
- **Deliver Fast:** Shorter cycle times reduce the risk of building the wrong thing. Emphasize continuous delivery.

## 2. Mob Programming (Ensemble Programming)
- **Concept:** All the brilliant minds working on the same thing, at the same time, in the same space, and at the same computer.
- **Roles:** The "Driver" physically interacts with the keyboard, while the "Navigators" discuss, guide, and dictate the code to be typed. Positions rotate constantly (e.g., every 10-15 minutes).
- **Benefits:** Eliminates PR review wait times entirely, standardizes coding styles across the team naturally, eliminates knowledge silos instantly, and provides continuous, real-time code review.
- **When to Use:** Particularly effective for complex architectural tasks, tackling severe bugs/incidents, and onboarding new developers rapidly.
