## 🛡️ Governance & Safety (Tiered Veto System)
Our `veto-conditions.yaml` acts as the immune system of the squad, preventing bad architectural or code decisions from propagating:
- **Tier 0:** System-changing impact (e.g., No structural changes without an ADR).
- **Tier 1:** Coding standards (e.g., Strict cyclomatic complexity limits).
- **Tier 2:** Specialist mandates (e.g., Security & Audit approvals required).
