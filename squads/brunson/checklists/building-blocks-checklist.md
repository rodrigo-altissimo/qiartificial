# 31 Building Blocks Review Checklist

> Source: DotCom Secrets - Funnel Building Blocks (Section 3)
> Version: 1.0
> Use: When assembling funnel pages to ensure all essential elements are present

---

## Pre-Requisites
- [ ] Funnel type selected
- [ ] Offer and Value Ladder defined
- [ ] Copy framework chosen
- [ ] Design assets prepared

---

## STEP 1: Pre-Frame Building Blocks

### 1.1 Traffic Pre-Frame
- [ ] Ad creative matches landing page message (congruence)
- [ ] Email pre-frame sets correct expectations
- [ ] Blog post or content pre-frames the offer
- [ ] Social media post aligns with funnel entry point
- [ ] Influencer endorsement frames authority (if applicable)

### 1.2 Bridge Pages
- [ ] Bridge page exists between traffic source and offer
- [ ] Video or article warms up cold traffic
- [ ] Personal story creates connection before selling
- [ ] Bridge addresses main objection of traffic source

---

## STEP 2: Page Building Blocks

### 2.1 Squeeze Page Elements
- [ ] Curiosity-driven headline present
- [ ] Benefit-focused sub-headline
- [ ] Minimal form fields (email only or name + email)
- [ ] CTA button with action-oriented text
- [ ] No exit navigation or competing links

### 2.2 Sales Page Elements
- [ ] Headline grabs attention and states benefit
- [ ] Opening story or hook in first 3 sentences
- [ ] Problem agitation section present
- [ ] Solution introduction with unique mechanism
- [ ] Bullet points listing specific benefits
- [ ] Testimonials and social proof placed strategically
- [ ] Offer stack with value breakdown
- [ ] Price reveal with anchoring
- [ ] Guarantee displayed prominently
- [ ] Scarcity or urgency element (genuine)
- [ ] Final CTA with clear next step

### 2.3 Order Form Elements
- [ ] Two-step order form implemented
- [ ] Order summary visible during checkout
- [ ] Order bump positioned above payment fields
- [ ] Trust badges and security symbols present
- [ ] Money-back guarantee restated near payment

---

## STEP 3: OTO Building Blocks

### 3.1 Upsell Page Elements
- [ ] "Wait! Your order is not complete" headline pattern
- [ ] Complementary offer to original purchase
- [ ] One-click purchase button (no re-enter payment)
- [ ] Discounted price or exclusive bundle
- [ ] Clear "No thanks" decline link visible

### 3.2 Downsell Page Elements
- [ ] Lower-priced alternative to declined upsell
- [ ] Different angle or payment plan option
- [ ] Maintains value perception while reducing commitment
- [ ] Still profitable at reduced price point

---

## STEP 4: Thank You Page Blocks

### 4.1 Confirmation Elements
- [ ] Purchase confirmation and receipt info
- [ ] Clear next steps and what to expect
- [ ] Access instructions (login, download, etc.)
- [ ] Welcome video from founder/creator
- [ ] Social share buttons or referral incentive

### 4.2 Ascension Elements
- [ ] Next offer teaser on thank-you page
- [ ] Community invitation (Facebook group, etc.)
- [ ] Survey for segmentation and feedback
- [ ] Calendar link for onboarding call (if applicable)

---

## STEP 5: Follow-Up Building Blocks

### 5.1 Email Sequences
- [ ] Immediate confirmation email sends
- [ ] Soap Opera Sequence loaded (5 emails)
- [ ] Seinfeld Emails scheduled for ongoing engagement
- [ ] Segmentation triggers based on behavior

### 5.2 Retargeting
- [ ] Pixel fires on all funnel pages
- [ ] Custom audiences created per funnel step
- [ ] Retargeting ads designed for non-converters
- [ ] Exclusion audiences set for buyers

---

## Validation
- [ ] Every page has ONE primary call to action
- [ ] No page has navigation that leaks traffic
- [ ] Message congruence maintained from ad to thank-you
- [ ] All building blocks serve the funnel goal
- [ ] Funnel reviewed by someone unfamiliar with it

---

## Scoring
- 38-42/42 = Complete funnel with all blocks in place
- 30-37/42 = Strong funnel, add missing blocks
- 22-29/42 = Key blocks missing, prioritize additions
- Below 22 = Rebuild funnel using building block framework
