# False Belief Pattern Mapping Checklist

> Source: Expert Secrets, Chapters 7-9 - The 3 Types of False Beliefs
> Version: 1.0
> Use: When mapping and breaking false beliefs for presentations and copy

---

## Pre-Requisites
- [ ] Big Domino identified
- [ ] Dream customer avatar complete with psychographics
- [ ] New Opportunity defined
- [ ] At least 10 customer conversations or survey responses reviewed

---

## STEP 1: Vehicle-Related False Beliefs

### 1.1 Belief Discovery
- [ ] Listed 5-10 false beliefs about the VEHICLE (your new opportunity)
- [ ] These are beliefs like "This type of thing doesn't work"
- [ ] Examples: "Funnels don't work in my industry" / "Online courses are scams"
- [ ] Each belief sourced from actual customer language
- [ ] Beliefs ranked by prevalence and blocking power

### 1.2 Belief Breaking Strategy
- [ ] Each vehicle false belief has a counter-story (Epiphany Bridge)
- [ ] Counter-story shows HOW you or someone overcame this exact belief
- [ ] Story follows: backstory -> journey -> new opportunity -> transformation
- [ ] Evidence/proof supports each story
- [ ] Top 3 vehicle beliefs selected for presentation use

---

## STEP 2: Internal False Beliefs

### 2.1 Belief Discovery
- [ ] Listed 5-10 false beliefs about THEMSELVES
- [ ] These are "I can't because I..." beliefs
- [ ] Examples: "I'm not tech-savvy enough" / "I don't have enough time"
- [ ] Focus on self-doubt, ability, and worthiness beliefs
- [ ] Beliefs ranked by how paralyzing they are

### 2.2 Belief Breaking Strategy
- [ ] Each internal false belief has an Epiphany Bridge story
- [ ] Stories feature relatable characters who had the SAME doubt
- [ ] Characters overcame through the unique mechanism you teach
- [ ] Stories emphasize "if they can, you can" message
- [ ] Top 3 internal beliefs selected for presentation use

---

## STEP 3: External False Beliefs

### 3.1 Belief Discovery
- [ ] Listed 5-10 false beliefs about EXTERNAL factors
- [ ] These are "I can't because [outside force]..." beliefs
- [ ] Examples: "The market is too saturated" / "The economy is bad"
- [ ] Focus on timing, competition, economy, technology barriers
- [ ] Beliefs ranked by how commonly cited they are

### 3.2 Belief Breaking Strategy
- [ ] Each external false belief has an Epiphany Bridge story
- [ ] Stories show people succeeding DESPITE these external factors
- [ ] Stories reframe the external factor as an advantage
- [ ] Evidence counters the excuse directly
- [ ] Top 3 external beliefs selected for presentation use

---

## STEP 4: Belief Stack Organization

### 4.1 Three Secrets Mapping
- [ ] Secret #1 addresses the top Vehicle false belief
- [ ] Secret #2 addresses the top Internal false belief
- [ ] Secret #3 addresses the top External false belief
- [ ] Each Secret has one Epiphany Bridge story
- [ ] Each Secret has supporting evidence and proof

### 4.2 Story Inventory
- [ ] Minimum 9 Epiphany Bridge stories collected (3 per category)
- [ ] Each story is 3-5 minutes when told verbally
- [ ] Stories are emotionally compelling (not just logical)
- [ ] Stories feature diverse characters (various backgrounds)
- [ ] Stories rehearsed and refined for impact

---

## STEP 5: Belief-to-Close Connection

### 5.1 From Belief to Action
- [ ] After all 3 false belief categories addressed, prospect should believe:
  - The vehicle works (Vehicle beliefs broken)
  - They can do it (Internal beliefs broken)
  - Now is the right time (External beliefs broken)
- [ ] Close naturally follows as "the only logical next step"
- [ ] Stack Slide reinforces the new beliefs with value proof
- [ ] Guarantee addresses any remaining belief residue

### 5.2 Objection Pre-Handling
- [ ] Top 10 objections mapped to one of the 3 false belief categories
- [ ] Each objection is addressed BEFORE the close (not after)
- [ ] No new false beliefs introduced by your own presentation
- [ ] FAQ section addresses remaining edge-case beliefs

---

## Validation
- [ ] Complete False Belief Matrix documented (3 categories x 5+ beliefs)
- [ ] Top 9 beliefs have corresponding Epiphany Bridge stories
- [ ] Three Secrets structure validated against false beliefs
- [ ] Tested: prospects feel empowered, not overwhelmed, after hearing
- [ ] Matrix updated quarterly based on new customer feedback

---

## Scoring
- 30-34/34 = Comprehensive false belief mapping
- 24-29/34 = Strong mapping, add more stories
- 18-23/34 = Gaps in belief coverage
- Below 18 = Return to customer research before proceeding
