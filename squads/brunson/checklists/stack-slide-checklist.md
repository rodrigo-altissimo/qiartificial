# Stack Slide Design Checklist

> Source: Expert Secrets, Chapter 13 - The Stack
> Version: 1.0
> Use: When designing the Stack Slide for webinar or presentation closes

---

## Pre-Requisites
- [ ] Core offer defined with all components
- [ ] Price point determined
- [ ] Bonuses selected and created
- [ ] Guarantee type chosen

---

## STEP 1: Offer Components

### 1.1 Core Offer (Main Program/Product)
- [ ] Main offer named with compelling title
- [ ] Clear description of what is included
- [ ] Assigned value (what it WOULD cost separately)
- [ ] Delivery method clear (course, coaching, software, etc.)
- [ ] Core offer alone justifies the price

### 1.2 Component Stacking
- [ ] Minimum 5 components in the stack
- [ ] Each component has its own name and value
- [ ] Components build on each other logically
- [ ] Components address different aspects of the transformation
- [ ] Each component feels like a standalone product

### 1.3 Component Types to Include
- [ ] Main training/course/program (the core)
- [ ] Tools/templates/swipe files (implementation aids)
- [ ] Community access (support and accountability)
- [ ] Live calls or coaching (personal guidance)
- [ ] Bonus training (complementary skill)

---

## STEP 2: Value Assignment

### 2.1 Value Pricing
- [ ] Each component has a believable standalone value
- [ ] Values are based on what similar items sell for
- [ ] Total stack value is 10x or more of the actual price
- [ ] Values are not so inflated they feel unbelievable
- [ ] Each value can be justified if questioned

### 2.2 Value Anchoring
- [ ] Total value calculated and displayed prominently
- [ ] Price revealed AFTER full stack is presented
- [ ] Gap between total value and price is dramatic
- [ ] "If all this did was [one thing], would it be worth [price]?" test
- [ ] Multiple "would it be worth it?" closes throughout

---

## STEP 3: Bonus Strategy

### 3.1 Bonus Selection
- [ ] Bonuses complement (not repeat) the core offer
- [ ] Each bonus addresses a specific objection or desire
- [ ] Bonuses have clear titles and descriptions
- [ ] At least 1 bonus creates FOMO (fast-action only)
- [ ] Bonuses are genuinely valuable (not filler)

### 3.2 Fast-Action Bonuses
- [ ] Time-limited bonus for immediate purchasers
- [ ] Bonus is highly desirable and exclusive
- [ ] Clear deadline for fast-action bonus
- [ ] Bonus alone could justify the purchase for some
- [ ] Creates urgency without being manipulative

---

## STEP 4: Slide Design

### 4.1 Visual Layout
- [ ] Clean, uncluttered design
- [ ] Each component added ONE at a time (stacking visually)
- [ ] Running total of value visible as items are added
- [ ] Final price contrasted against total value
- [ ] Call-to-action button/link prominent

### 4.2 Stacking Sequence
- [ ] Core offer presented first with full description
- [ ] Each subsequent item stacked below with its value
- [ ] Bonuses presented after core components
- [ ] Fast-action bonus presented last (with urgency)
- [ ] Price reveal is the dramatic climax of the stack

### 4.3 Price Presentation
- [ ] Original/total value shown (crossed out or contrasted)
- [ ] Actual price shown much smaller in comparison
- [ ] Payment plan option displayed (if available)
- [ ] Savings amount calculated and highlighted
- [ ] "Not [total value], not [middle price], just [actual price]"

---

## STEP 5: Stack Presentation Script

### 5.1 Verbal Delivery
- [ ] Each component introduced with enthusiasm
- [ ] Brief description of WHY this component matters
- [ ] Value stated for each: "A $X value"
- [ ] Running total updated: "That's already $X in value"
- [ ] Pause for effect after price reveal

### 5.2 Close Integration
- [ ] Stack transitions smoothly into guarantee
- [ ] "Who is this for" segment follows the stack
- [ ] Final CTA immediately after stack presentation
- [ ] Objection handling addresses remaining concerns
- [ ] Stack repeated/summarized in closing email

---

## Validation
- [ ] Stack has minimum 5 components plus bonuses
- [ ] Total perceived value exceeds 10x the price
- [ ] Stack visually compelling and easy to read
- [ ] Verbal presentation rehearsed and timed
- [ ] Stack Slide used consistently in all sales presentations

---

## Scoring
- 28-32/32 = Irresistible Stack Slide
- 22-27/32 = Strong stack, enhance bonuses or values
- 16-21/32 = Stack needs more components or better values
- Below 16 = Redesign stack from offer foundations
