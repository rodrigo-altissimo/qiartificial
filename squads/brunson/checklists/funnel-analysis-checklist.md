# Funnel Analysis Checklist

> Agent: brunson-swipe
> Source: DotCom Secrets - Funnel Hacking & Competitive Analysis
> Version: 1.0
> Use: When conducting a structured analysis of any funnel (own or competitor)

---

## Pre-Requisites
- [ ] Target funnel URL and entry point documented
- [ ] Screenshot/recording tools ready
- [ ] Comparison benchmarks defined (industry averages or goals)
- [ ] Analysis framework document prepared for notes

---

## STEP 1: Traffic Analysis

### 1.1 Traffic Sources
- [ ] Primary traffic sources identified (paid, organic, social, email)
- [ ] Ad creatives documented (screenshots of ads)
- [ ] Hooks used in traffic sources cataloged
- [ ] Traffic temperature assessed (cold, warm, hot for each source)

### 1.2 Traffic Volume Estimation
- [ ] Monthly visitor estimate obtained (SimilarWeb or similar)
- [ ] Ad spend indicators noted (number of active ads, duration)
- [ ] Organic reach assessed (social followers, SEO rankings)
- [ ] Traffic diversity evaluated (single source vs multi-channel)

---

## STEP 2: Funnel Structure

### 2.1 Funnel Type Identification
- [ ] Funnel type classified (squeeze, tripwire, webinar, application, etc.)
- [ ] Number of pages in the funnel documented
- [ ] Complete page flow mapped (page 1 --> page 2 --> etc.)
- [ ] Upsell/downsell paths documented

### 2.2 Page-by-Page Breakdown
- [ ] Each page screenshotted (full page, top to bottom)
- [ ] Headline and sub-headline of each page documented
- [ ] CTA text and placement noted for each page
- [ ] Design elements and layout patterns recorded

### 2.3 Pre-Frame Analysis
- [ ] Pre-frame between traffic source and landing page assessed
- [ ] Pre-frame between each page transition evaluated
- [ ] Congruence from ad to landing page rated (1-10)
- [ ] Bridge pages or warming elements identified

---

## STEP 3: Offer Analysis

### 3.1 Frontend Offer
- [ ] Frontend offer clearly described
- [ ] Price point documented
- [ ] Value proposition summarized in one sentence
- [ ] Positioning (new opportunity vs improvement) noted

### 3.2 Value Stack
- [ ] All offer components listed with stated values
- [ ] Total value stack calculated
- [ ] Value-to-price ratio determined
- [ ] Bonuses and their strategic purpose analyzed

### 3.3 Upsell/OTO Offers
- [ ] Each upsell documented (offer, price, positioning)
- [ ] Logical connection between upsells and core offer noted
- [ ] Average cart value estimated (frontend + upsells)
- [ ] Downsell strategy analyzed

---

## STEP 4: Copy & Persuasion Analysis

### 4.1 Hook Analysis
- [ ] Primary hook identified and classified (type)
- [ ] Hook effectiveness rated (1-10)
- [ ] Sub-hooks throughout the funnel documented
- [ ] Hook uniqueness assessed vs competitors

### 4.2 Story Elements
- [ ] Epiphany Bridge stories identified in the copy
- [ ] False beliefs being addressed cataloged
- [ ] Emotional arc of the copy mapped
- [ ] Storytelling effectiveness rated (1-10)

### 4.3 Social Proof
- [ ] Types of social proof used (testimonials, logos, numbers)
- [ ] Quantity and quality of testimonials assessed
- [ ] Placement of social proof in the funnel noted
- [ ] Credibility elements documented

---

## STEP 5: Strengths & Weaknesses

### 5.1 Strengths
- [ ] Top 3 strongest elements of the funnel identified
- [ ] What makes this funnel effective documented
- [ ] Elements worth modeling in your own funnel noted
- [ ] Unique innovations or approaches recognized

### 5.2 Weaknesses
- [ ] Top 3 weakest elements identified
- [ ] Missed opportunities or gaps documented
- [ ] Areas where your funnel can outperform this one noted
- [ ] Specific improvements you would make listed

---

## Validation
- [ ] Complete funnel flow documented with screenshots from entry to exit
- [ ] Offer, pricing, and value stack fully analyzed
- [ ] At least 3 actionable insights extracted
- [ ] Analysis compared against your own funnel (if applicable)
- [ ] Analysis report compiled and stored in swipe file

---

## Scoring
- 30-34/34 = Comprehensive funnel analysis, full intelligence
- 24-29/34 = Strong analysis, minor areas to expand
- 18-23/34 = Partial analysis, key sections need depth
- Below 18 = Incomplete analysis, revisit systematically
