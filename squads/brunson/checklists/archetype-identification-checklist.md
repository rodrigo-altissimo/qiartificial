# Archetype Identification Checklist

> Agent: brunson-swipe
> Source: DotCom Secrets - Funnel Types & Archetype Classification
> Version: 1.0
> Use: When classifying a funnel into its archetype for analysis or replication

---

## Pre-Requisites
- [ ] Target funnel fully documented (pages, flow, offers)
- [ ] Funnel analysis or reverse engineering complete
- [ ] Knowledge of core funnel archetypes (see Step 1 below)
- [ ] Comparison funnels identified in the same niche

---

## STEP 1: Identify the Funnel Archetype

### 1.1 Lead Generation Funnels
- [ ] Squeeze Page Funnel: Simple opt-in for lead magnet
- [ ] Survey Funnel: Segmentation quiz leading to tailored offer
- [ ] Summit/Challenge Funnel: Multi-day event for list building
- [ ] Book Funnel: Free + shipping book offer for lead gen

### 1.2 Sales Funnels
- [ ] Tripwire Funnel: Low-ticket frontend with upsell chain
- [ ] VSL Funnel: Video Sales Letter driving a single offer
- [ ] Sales Letter Funnel: Long-form copy driving a mid-ticket offer
- [ ] Product Launch Funnel: Sequence of content leading to cart open

### 1.3 Presentation Funnels
- [ ] Perfect Webinar Funnel: Webinar registration --> presentation --> offer
- [ ] Auto-Webinar Funnel: Automated version of the webinar funnel
- [ ] Challenge Funnel: 5-30 day challenge ending with offer
- [ ] Mini-Class Funnel: Short training series leading to offer

### 1.4 High-Ticket Funnels
- [ ] Application Funnel: Application form --> phone call --> close
- [ ] Two-Step Funnel: Short presentation --> application --> call
- [ ] Event Funnel: Live event registration --> event --> pitch

---

## STEP 2: Archetype Characteristics

### 2.1 Traffic Temperature Match
- [ ] Funnel archetype matches the traffic temperature being used
- [ ] Cold traffic --> lead gen or low-ticket frontend
- [ ] Warm traffic --> presentation or mid-ticket funnels
- [ ] Hot traffic --> application or high-ticket funnels
- [ ] Temperature mismatch identified (if any)

### 2.2 Price Point Alignment
- [ ] Funnel complexity matches the price point
- [ ] Low-ticket ($7-$97): simple, fast, few pages
- [ ] Mid-ticket ($97-$997): more education, more pages
- [ ] High-ticket ($997+): application, phone call, more trust-building
- [ ] Price-to-funnel-length ratio appropriate

### 2.3 Industry Pattern Match
- [ ] Archetype is standard for this industry/niche
- [ ] Or: archetype is deliberately different (competitive advantage?)
- [ ] Similar successful funnels in the niche use this archetype
- [ ] Archetype has proven results in this market

---

## STEP 3: Component Analysis by Archetype

### 3.1 Standard Components Present
- [ ] All expected pages for this archetype type exist
- [ ] Page flow matches the archetype template
- [ ] No missing critical steps in the funnel path
- [ ] Components are in the expected order

### 3.2 Archetype Innovations
- [ ] Any deviations from standard archetype identified
- [ ] Deviations assessed: improvement or mistake?
- [ ] Innovations documented for possible adoption
- [ ] Standard elements that were removed noted (and why?)

### 3.3 Hybrid Archetype Detection
- [ ] Funnel combines elements from multiple archetypes?
- [ ] If hybrid: which archetypes are combined?
- [ ] Hybrid approach assessed: synergistic or confusing?
- [ ] Dominant archetype identified in the hybrid

---

## STEP 4: Archetype Benchmarking

### 4.1 Performance Expectations
- [ ] Industry-standard conversion rates for this archetype noted
- [ ] Average cart value benchmarks documented
- [ ] Traffic cost expectations for this funnel type estimated
- [ ] ROI expectations set based on archetype performance data

### 4.2 Comparative Analysis
- [ ] This funnel compared to 2-3 other funnels of same archetype
- [ ] Relative strengths and weaknesses identified
- [ ] Best-in-class example for this archetype documented
- [ ] Gaps between this funnel and best-in-class listed

---

## STEP 5: Archetype Application

### 5.1 Replication Decision
- [ ] Should you use this same archetype? (yes/no with reasoning)
- [ ] If yes: what elements to model directly?
- [ ] If no: what alternative archetype fits your situation better?
- [ ] Adaptation plan for your specific niche and audience

### 5.2 Archetype Optimization
- [ ] Known weaknesses of this archetype addressed
- [ ] Complementary funnels identified (stack multiple archetypes)
- [ ] Testing priorities defined based on archetype analysis
- [ ] Timeline for building your version planned

---

## Validation
- [ ] Funnel archetype correctly classified with confidence
- [ ] All standard components for the archetype accounted for
- [ ] Benchmarks and expectations set based on archetype
- [ ] Application plan created for your own funnel
- [ ] Analysis stored in swipe file for future reference

---

## Scoring
- 28-32/32 = Complete archetype analysis with actionable blueprint
- 22-27/32 = Strong classification, minor gaps in benchmarking
- 16-21/32 = Archetype identified but analysis is shallow
- Below 16 = Classification unclear, revisit with more data
