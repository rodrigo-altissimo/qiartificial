# Funnel Architecture Checklist

> Source: DotCom Secrets, Chapters 8-10 + Traffic Secrets
> Version: 1.0
> Use: When validating the page flow and technical setup of a funnel

---

## Pre-Requisites
- [ ] Funnel type selected and validated
- [ ] Offer stack defined
- [ ] Copy and creative assets available
- [ ] Funnel builder tool chosen (ClickFunnels, etc.)

---

## STEP 1: Page Flow Validation

### 1.1 Entry Point
- [ ] Landing page URL is clean and memorable
- [ ] Page loads in under 3 seconds
- [ ] Mobile-responsive design verified
- [ ] One clear CTA above the fold
- [ ] No navigation links that leak traffic
- [ ] Tracking pixels installed (Facebook, Google, etc.)

### 1.2 Opt-In/Capture Page
- [ ] Headline matches the ad/traffic source promise
- [ ] Form fields minimized (name + email at most)
- [ ] Privacy policy and terms linked
- [ ] Thank-you/confirmation page set up
- [ ] Email integration tested and confirmed

### 1.3 Sales Page Flow
- [ ] Pre-frame matches traffic source expectations
- [ ] Sales page follows proven framework (AIDA, PAS, etc.)
- [ ] Order form is on-page or one click away
- [ ] Price and offer clearly stated
- [ ] Guarantee displayed prominently
- [ ] Testimonials and social proof present

---

## STEP 2: Order Flow

### 2.1 Order Form Page
- [ ] Two-step order form (contact info then payment)
- [ ] Order bump offer present and positioned correctly
- [ ] Order bump adds 15-30% to average order value
- [ ] SSL certificate active (https://)
- [ ] Payment processor connected and tested
- [ ] Multiple payment options available (card, PayPal)

### 2.2 OTO (One-Time Offer) Sequence
- [ ] OTO 1 immediately after purchase (complementary offer)
- [ ] OTO 2 follows OTO 1 (expansion or upgrade offer)
- [ ] Downsell page for each OTO rejection
- [ ] Each OTO has one-click upsell (no re-enter payment)
- [ ] OTO pages have countdown or urgency element
- [ ] "No thanks" link clearly visible on each OTO

---

## STEP 3: Post-Purchase Flow

### 3.1 Thank You / Confirmation Page
- [ ] Order confirmation details displayed
- [ ] Next steps clearly communicated
- [ ] Access instructions provided immediately
- [ ] Share/referral mechanism offered
- [ ] Buyer added to customer email list

### 3.2 Delivery Mechanism
- [ ] Digital product access is instant
- [ ] Member area login works (if applicable)
- [ ] Welcome email sent with access details
- [ ] Support contact information provided

---

## STEP 4: Technical Infrastructure

### 4.1 Integrations
- [ ] Email autoresponder connected (all forms)
- [ ] CRM tagging/segmentation configured
- [ ] Payment processor handling all price points
- [ ] Analytics tracking on every page
- [ ] Retargeting pixels on all pages

### 4.2 Testing
- [ ] Full purchase flow tested (real transaction)
- [ ] Each OTO tested for accept AND decline paths
- [ ] Email sequences trigger correctly
- [ ] Mobile purchase flow tested end-to-end
- [ ] Different browsers tested (Chrome, Safari, Firefox)

---

## STEP 5: Funnel Metrics Setup

### 5.1 KPI Tracking
- [ ] Opt-in rate trackable (target: 20-50%)
- [ ] Sales conversion rate trackable
- [ ] Average order value (AOV) calculable
- [ ] Earnings per click (EPC) calculable
- [ ] Cost per acquisition (CPA) trackable

---

## Validation
- [ ] Complete funnel walkthrough with fresh eyes (no cached data)
- [ ] All links work and point to correct pages
- [ ] No broken images or missing assets
- [ ] Speed test passed on all pages
- [ ] Legal pages accessible (privacy, terms, refund policy)

---

## Scoring
- 30-34/34 = Launch-ready architecture
- 24-29/34 = Minor fixes needed before launch
- 18-23/34 = Significant gaps to address
- Below 18 = Major rebuild required
