# Event Funnel Checklist

> Agent: brunson-launch
> Source: Expert Secrets & Traffic Secrets - Event Funnels & Live Events
> Version: 1.0
> Use: When planning or auditing an event funnel (virtual or in-person)

---

## Pre-Requisites
- [ ] Event type defined (virtual summit, live workshop, conference, masterclass)
- [ ] Event date and duration set
- [ ] Target audience and ideal attendee profile clear
- [ ] Backend offer (pitch during/after event) prepared
- [ ] Venue or virtual platform selected and configured

---

## STEP 1: Registration Funnel

### 1.1 Registration Page
- [ ] Event headline creates excitement and urgency
- [ ] Key benefits of attending listed (what they will learn/get)
- [ ] Speaker/host credibility established
- [ ] Date, time, and format clearly stated
- [ ] Registration form is simple (name + email minimum)
- [ ] Social proof (past event testimonials, attendee count)

### 1.2 Registration Confirmation
- [ ] Confirmation page thanks registrant and sets expectations
- [ ] Calendar invite option provided (add to Google Calendar, etc.)
- [ ] "Share with a friend" prompt included
- [ ] Optional: early-bird or VIP upgrade offer presented

### 1.3 Reminder Sequences
- [ ] Email reminders scheduled: 7 days, 3 days, 1 day, 1 hour before
- [ ] Each reminder adds value (tip, teaser, speaker spotlight)
- [ ] SMS reminders set up if applicable
- [ ] Show-up rate optimization tactics deployed (commitment prompt)

---

## STEP 2: Pre-Event Engagement

### 2.1 Content Warmup
- [ ] Pre-event content builds excitement and primes for the offer
- [ ] Stories and testimonials from past events shared
- [ ] False beliefs addressed before the event begins
- [ ] Attendees feel prepared and eager to participate

### 2.2 Community Building
- [ ] Event-specific community space created (Facebook group, Slack, etc.)
- [ ] Attendees encouraged to introduce themselves and share goals
- [ ] Networking opportunities highlighted
- [ ] Pre-event challenges or activities drive early engagement

---

## STEP 3: Event Execution

### 3.1 Opening
- [ ] Event opens with energy, excitement, and welcome
- [ ] Ground rules and expectations set (how to participate)
- [ ] Big promise of the event stated ("By the end, you will...")
- [ ] Attendees engaged immediately (poll, question, exercise)

### 3.2 Content Delivery
- [ ] Content follows the Three Secrets framework (or similar)
- [ ] Each content block addresses a false belief
- [ ] Teaching is interspersed with Epiphany Bridge stories
- [ ] Attendees receive genuine value (not just a pitch-fest)
- [ ] Energy management: breaks, variety, interaction throughout

### 3.3 The Offer (Stack Slide)
- [ ] Transition from content to offer is natural and earned
- [ ] Stack Slide presentation builds value component by component
- [ ] Total value stated before price reveal
- [ ] Price anchored against value and alternatives
- [ ] Guarantee and risk reversal clearly presented
- [ ] Clear, urgent CTA (limited-time event pricing)

### 3.4 Close
- [ ] Urgency created with event-only pricing/bonuses
- [ ] Q&A addresses remaining objections
- [ ] Final CTA with simple instructions to purchase
- [ ] Non-buyers offered a consolation prize or next step

---

## STEP 4: Post-Event Follow-Up

### 4.1 Buyer Follow-Up
- [ ] Purchase confirmation and access delivered immediately
- [ ] Welcome email with onboarding instructions sent
- [ ] Post-event high communicated on (excitement, results)
- [ ] Ascension offer scheduled for 7-14 days later

### 4.2 Non-Buyer Follow-Up
- [ ] "Missed the event" replay or summary offered (if applicable)
- [ ] Objection-handling email sequence triggered
- [ ] Limited-time post-event offer extended (48-72 hours)
- [ ] Add to ongoing Seinfeld email list
- [ ] Down-sell or alternative offer presented

### 4.3 Attendee Feedback
- [ ] Post-event survey sent (what did they love, what to improve)
- [ ] Testimonials collected from enthusiastic attendees
- [ ] Net Promoter Score or satisfaction rating gathered
- [ ] Feedback incorporated into next event plan

---

## STEP 5: Event Optimization

### 5.1 Metrics Review
- [ ] Registration-to-show-up rate calculated (target: 30-50%)
- [ ] Show-up-to-stay rate calculated
- [ ] Offer conversion rate calculated (target: 5-15%)
- [ ] Revenue per attendee calculated
- [ ] Cost per registration and ROI calculated

### 5.2 Evergreen Potential
- [ ] Event content recorded for replay funnel
- [ ] Automated event funnel considered (auto-webinar, on-demand)
- [ ] Best segments identified for repurposing as content
- [ ] Next live event date planned based on debrief insights

---

## Validation
- [ ] Complete event funnel tested from registration to post-event
- [ ] All emails and reminders firing correctly
- [ ] Event technology tested (platform, streaming, slides, links)
- [ ] Offer page and checkout verified during event
- [ ] Post-event sequences triggered correctly for buyers and non-buyers

---

## Scoring
- 34-38/38 = Well-orchestrated event funnel
- 27-33/38 = Strong event, refine follow-up or conversion
- 20-26/38 = Event happened but significant gaps in execution
- Below 20 = Event funnel needs foundational rebuilding
