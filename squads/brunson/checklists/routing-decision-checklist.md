# Routing Decision Checklist

> Agent: brunson-chief
> Source: DotCom Secrets - Funnel Strategy & Secret Formula
> Version: 1.0
> Use: When determining which agent, funnel type, or workflow to route a request to

---

## Pre-Requisites
- [ ] Business type and niche clearly identified
- [ ] Current funnel assets inventoried (pages, emails, offers)
- [ ] Primary goal defined (leads, sales, ascension, retention)
- [ ] Traffic source and temperature understood (cold/warm/hot)

---

## STEP 1: Identify the Core Objective

### 1.1 What Is the Primary Outcome?
- [ ] Lead generation (new subscribers) --> Squeeze funnel path
- [ ] Frontend sale (self-liquidating offer) --> Tripwire funnel path
- [ ] Webinar/presentation sale --> Webinar funnel path
- [ ] High-ticket close --> Application funnel path
- [ ] Product launch --> Launch funnel path
- [ ] Ascension of existing buyers --> Follow-up funnel path

### 1.2 Where Is the Customer on the Value Ladder?
- [ ] Unaware (needs lead magnet) --> brunson-pages + brunson-hooks
- [ ] Aware but not yet buyer --> brunson-copy + brunson-offers
- [ ] Existing buyer (needs ascension) --> brunson-email + brunson-offers
- [ ] High-value customer (needs premium path) --> brunson-webinar + brunson-copy

---

## STEP 2: Match to Agent Specialty

### 2.1 Content & Messaging Needs
- [ ] Needs hooks and attention-grabbers --> brunson-hooks
- [ ] Needs story-driven persuasion --> brunson-stories
- [ ] Needs sales copy or VSL --> brunson-copy
- [ ] Needs email sequences --> brunson-email

### 2.2 Funnel & Architecture Needs
- [ ] Needs funnel type selection --> brunson-funnels
- [ ] Needs page design/structure --> brunson-pages
- [ ] Needs traffic plan --> brunson-traffic
- [ ] Needs webinar/presentation --> brunson-webinar

### 2.3 Strategy & Analysis Needs
- [ ] Needs offer creation/stacking --> brunson-offers
- [ ] Needs competitive analysis --> brunson-swipe
- [ ] Needs community/movement building --> brunson-movement
- [ ] Needs funnel audit/health check --> brunson-advisor
- [ ] Needs launch planning --> brunson-launch

---

## STEP 3: Validate the Routing

### 3.1 Dependency Check
- [ ] Required upstream assets exist (e.g., offer before copy)
- [ ] Pre-requisite checklists for target agent are satisfiable
- [ ] No circular dependencies in the routing path
- [ ] Agent has all inputs needed to begin work

### 3.2 Sequencing Validation
- [ ] Routing follows natural funnel-building order
- [ ] Strategy precedes execution tasks
- [ ] Copy and hooks come before page assembly
- [ ] Traffic planning follows funnel completion

---

## Validation
- [ ] Routing decision documented with rationale
- [ ] Selected agent confirmed as best match for objective
- [ ] Handoff information complete (context, assets, goals)
- [ ] Fallback routing identified if primary path is blocked
- [ ] Timeline expectations set for deliverable

---

## Scoring
- 22-25/25 = Clear routing, proceed immediately
- 17-21/25 = Routing solid, clarify minor gaps
- 12-16/25 = Ambiguous routing, gather more context
- Below 12 = Insufficient information, return to discovery
