# Hook Library Checklist

> Agent: brunson-hooks
> Source: Traffic Secrets & DotCom Secrets - Hooks & Attention Mastery
> Version: 1.0
> Use: When building or auditing a hook library for any campaign or funnel

---

## Pre-Requisites
- [ ] Dream customer avatar fully defined
- [ ] Core offer(s) identified
- [ ] Competitor hooks researched (Dream 100 swipe file)
- [ ] Key pain points and desires cataloged
- [ ] Content platforms identified (where hooks will be deployed)

---

## STEP 1: Hook Categories

### 1.1 Question Hooks
- [ ] Minimum 5 question hooks written
- [ ] Each question targets a specific pain or curiosity
- [ ] Questions cannot be answered with "no" or dismissed easily
- [ ] Examples: "What if everything you knew about X was wrong?"

### 1.2 Bold Statement Hooks
- [ ] Minimum 5 bold statement hooks written
- [ ] Each makes a surprising or counterintuitive claim
- [ ] Statements are specific (include numbers or details)
- [ ] Examples: "I made $X in Y days doing Z"

### 1.3 Story Hooks
- [ ] Minimum 5 story-opening hooks written
- [ ] Each starts mid-action or at a dramatic moment
- [ ] Stories are relatable to the dream customer
- [ ] Examples: "Three years ago, I was about to quit..."

### 1.4 Curiosity Hooks
- [ ] Minimum 5 curiosity/open-loop hooks written
- [ ] Each creates an information gap that demands resolution
- [ ] Loops are genuinely interesting, not clickbait
- [ ] Examples: "The one thing every millionaire does that nobody talks about"

---

## STEP 2: Hook Inventory Management

### 2.1 Cataloging
- [ ] All hooks organized by category (question, statement, story, curiosity)
- [ ] Each hook tagged by platform (ad, email, video, social)
- [ ] Each hook tagged by traffic temperature (cold, warm, hot)
- [ ] Performance data tracked (CTR, engagement, conversion)

### 2.2 Minimum Volume
- [ ] Minimum 20 hooks in the library total
- [ ] At least 5 per category (4 categories)
- [ ] Fresh hooks added weekly or per campaign
- [ ] Underperforming hooks retired or rewritten

---

## STEP 3: Hook Testing Framework

### 3.1 A/B Testing
- [ ] Each campaign tests minimum 3 different hooks
- [ ] Hooks tested with same body copy (isolate the hook variable)
- [ ] Winning hooks documented and replicated
- [ ] Test budget allocated for hook experiments

### 3.2 Platform Adaptation
- [ ] Each hook adapted for different platforms
- [ ] Format matches platform norms (character limits, visual needs)
- [ ] Same core hook tested across 2+ platforms
- [ ] Platform-specific performance tracked

---

## STEP 4: Hook Quality Standards

### 4.1 Each Hook Must...
- [ ] Stop the scroll or interrupt the pattern
- [ ] Be relevant to the target audience (not random shock)
- [ ] Create desire or curiosity to consume more
- [ ] Be truthful and deliverable (not misleading clickbait)

### 4.2 Red Flags (Disqualifiers)
- [ ] NO vague or generic hooks ("This changed my life")
- [ ] NO hooks that could apply to any business
- [ ] NO hooks that promise without specificity
- [ ] NO hooks that alienate the target audience

---

## Validation
- [ ] Hook library has minimum 20 hooks across all categories
- [ ] Each hook rated for strength (1-5 stars)
- [ ] Top 5 hooks identified for immediate deployment
- [ ] Hooks reviewed by someone outside the project for clarity
- [ ] Library stored in accessible format for the team

---

## Scoring
- 24-28/28 = Robust hook library, ready for campaigns
- 18-23/28 = Good foundation, expand weak categories
- 12-17/28 = Hook library too thin, needs more volume
- Below 12 = Start from scratch with focused hook creation
