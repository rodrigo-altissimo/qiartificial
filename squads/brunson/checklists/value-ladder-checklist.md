# Value Ladder Design Checklist

> Source: DotCom Secrets, Chapter 1 - The Secret Formula
> Version: 1.0
> Use: When designing or validating a Value Ladder for any business

---

## Pre-Requisites
- [ ] Target market clearly defined (Dream Customer avatar complete)
- [ ] Core offer/product exists or is planned
- [ ] Competitor landscape researched
- [ ] Revenue goals established

---

## STEP 1: Ladder Foundation

### 1.1 Entry-Level Offer (Bait/Lead Magnet)
- [ ] Free or very low cost ($0-$7)
- [ ] Solves ONE specific problem for dream customer
- [ ] High perceived value relative to price
- [ ] Naturally leads to next rung on ladder
- [ ] Easy to consume (checklist, cheat sheet, mini-course)
- [ ] Delivers a quick win within 5-15 minutes

### 1.2 Frontend Offer (Tripwire/Self-Liquidating Offer)
- [ ] Priced $7-$97 range
- [ ] Converts free leads into paying customers
- [ ] Covers ad spend (self-liquidating)
- [ ] Provides more value than entry offer
- [ ] Creates buying momentum and habit

---

## STEP 2: Core Offer

### 2.1 Middle Tier
- [ ] Priced $97-$997 range
- [ ] Delivers comprehensive transformation
- [ ] Includes implementation support
- [ ] Has clear deliverables and timeline
- [ ] Solves a broader problem than frontend

### 2.2 Value Delivery
- [ ] More personal attention than lower tiers
- [ ] Includes community or group element
- [ ] Has accountability mechanisms
- [ ] Results are measurable and trackable

---

## STEP 3: Premium Tier

### 3.1 High-Ticket Offer
- [ ] Priced $997-$25,000+ range
- [ ] Maximum personal access or done-for-you
- [ ] Exclusive positioning (limited spots)
- [ ] Highest level of transformation
- [ ] Clear ROI justification for price point

### 3.2 Continuity Element
- [ ] At least ONE recurring revenue component exists
- [ ] Membership, subscription, or retainer model
- [ ] Ongoing value delivery mechanism
- [ ] Retention strategy defined

---

## STEP 4: Ladder Integrity

### 4.1 Ascension Logic
- [ ] Each rung naturally leads to the next
- [ ] Price increases are proportional to value increases
- [ ] No gaps larger than 10x between rungs
- [ ] Customer can see the path upward
- [ ] Each tier solves a deeper/broader version of the same core problem

### 4.2 Completeness Check
- [ ] Minimum 4 rungs on the ladder
- [ ] At least one offer at each price tier (free, low, mid, high)
- [ ] Downsell options exist for each major offer
- [ ] Cross-sell opportunities identified

---

## Validation
- [ ] Value Ladder sketched visually (ascending left to right)
- [ ] Each rung has a defined funnel type attached
- [ ] Revenue projections calculated per rung
- [ ] At least 3 people in target market would say "I'd buy that"
- [ ] Ladder compared against top 3 competitors

---

## Scoring
- 25-28/28 = Launch-ready Value Ladder
- 20-24/28 = Strong foundation, minor gaps
- 15-19/28 = Needs work on key rungs
- Below 15 = Redesign required
