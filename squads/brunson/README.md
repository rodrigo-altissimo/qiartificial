The Brunson Squad decomposes Russell Brunson's complete funnel methodology into 15 specialized agents. Each agent masters one specific domain -- from funnel architecture and traffic to webinar scripts and email sequences. Together, they form a full-stack funnel engineering system that can design, build, and optimize any funnel type from Brunson's playbook.

## Quick Start

### Activate the Orchestrator

The recommended entry point is `brunson-chief`, which routes your request to the correct specialist:

```bash
# Use the orchestrator (routes to correct specialist)
# Invoke via slash command:
/brunson:brunson-chief

# Or invoke specialists directly:
/brunson:brunson-funnels    # Funnel architecture & Value Ladder
/brunson:brunson-expert     # Expert positioning & Mass Movement
/brunson:brunson-traffic    # Dream 100 & traffic strategy
/brunson:brunson-webinar    # Perfect Webinar design
```

The Brunson Squad integrates with the Mente Lendaria MMOS (Mind Mapping Operating System):

| Setting | Value |
|---------|-------|
| **Enabled** | Yes |
| **Source Mind** | `russell_brunson` |
| **Log Source** | true |
| **Fallback Behavior** | Graceful |

All 15 agents map to the `russell_brunson` cognitive clone in `docs/minds/russell_brunson/`. This means each agent carries Brunson's voice patterns, thinking architecture, and communication DNA while specializing in their specific domain.

### How It Works

1. **Voice DNA** (`data/minds/brunson-voice-dna.yaml`) -- Shared Brunson communication patterns, phrases, metaphors
2. **Thinking DNA** (`data/minds/brunson-thinking-dna.yaml`) -- Core cognitive architecture and decision frameworks
3. **Agent DNA** (`data/minds/brunson-{agent}_dna.yaml`) -- Domain-specific cognitive profile per specialist
4. **MMOS Mind** (`docs/minds/russell_brunson/`) -- Full cognitive clone with raw data, analysis, synthesis, and system prompts
