# Stack Slide Framework

## Value Stacking for Irresistible Offers

---

## Overview

The Stack Slide is Russell Brunson's offer presentation technique used in the closing section of webinars, sales pages, and any selling scenario. Instead of presenting your offer as a single product with a single price, you systematically "stack" multiple components -- each with its own assigned value -- to build massive perceived worth. Then you reveal the actual price, which is a fraction of the stacked total. The gap between stacked value and actual price creates an "irresistible offer" -- one where saying no feels irrational. The Stack Slide is the single most important slide in the Perfect Webinar.

---

## Core Principles

1. **Value Before Price** -- Never reveal the price until the full value stack is built
2. **Each Component Gets Its Own Value** -- Every bonus, module, and resource has a specific dollar amount
3. **10x Value Gap** -- Total stacked value should be at least 10x the actual price
4. **Build Progressively** -- Add items one at a time, growing the total with each addition
5. **Anchor High** -- The first value mentioned sets the psychological anchor
6. **Name Everything** -- Unnamed bonuses feel generic; named components feel premium

## Stack Slide Architecture

### Layer 1: CORE OFFER

The main product or service being sold.

- Give it a compelling name (not just "my course")
- Assign a specific dollar value based on what it would cost to get this transformation elsewhere
- Describe the outcome, not just the content

**Example:** "Funnel Builder Secrets Masterclass -- $2,997 value"

### Layer 2: TOOLS AND RESOURCES

Practical tools that make implementation easier.

- Templates, swipe files, scripts, checklists
- Software access, trials, or licenses
- Workbooks and fill-in-the-blank documents

**Example:** "Funnel Template Library (23 proven templates) -- $1,997 value"

### Layer 3: SPEED AND IMPLEMENTATION

Elements that accelerate results.

- Quick-start guides
- Implementation checklists
- Done-for-you components
- Fast-action blueprints

**Example:** "30-Day Quick-Start Implementation Guide -- $497 value"

### Layer 4: COMMUNITY AND SUPPORT

Access to people and ongoing help.

- Facebook group or community access
- Q&A calls or office hours
- Coaching access (limited)
- Peer accountability

**Example:** "Private Funnel Hackers Community (12-month access) -- $1,997 value"

### Layer 5: EXCLUSIVE BONUSES

Scarcity-driven additions that increase urgency.

- Time-limited bonuses ("only available today")
- Bonus training or masterclass
- Personal review or audit
- Physical products shipped to their door

**Example:** "BONUS: Private Funnel Audit Session (only for first 50 action-takers) -- $2,000 value"

### Layer 6: GUARANTEE

Risk reversal that removes the final barrier.

- 30-day money-back guarantee
- Results guarantee
- "Better than money back" guarantee (keep everything even if you refund)

## Step-by-Step Application

1. **Define your core offer** -- What is the main transformation being sold?
2. **Name every component** -- Give each module, bonus, and tool its own name
3. **Assign individual values** -- What would each component cost if sold separately?
4. **Order from highest to lowest value** -- Start with the biggest number
5. **Create the visual stack** -- Build the slide or sales page section
6. **Add bonuses with urgency** -- "Only available if you act today"
7. **Sum the total value** -- Make the total prominently visible
8. **Reveal the price** -- Show the investment as a fraction of total value
9. **Add the guarantee** -- Remove all remaining risk
10. **Include payment plan option** -- Lower the barrier to entry

---

## Presentation Flow (During Webinar/Sales Page)

1. "Let me show you everything you are getting today..."
2. Add Component 1 to the slide. Pause. Let the value sink in.
3. "But that is not all. You are ALSO getting..."
4. Add Component 2. Running total increases.
5. Continue adding components, building excitement with each addition.
6. "So the total value of everything you see here is $X..."
7. "But you are NOT going to pay $X..."
8. "Your investment today is just $Y."
9. "And you are completely protected by my [guarantee]."
10. "Click the button below right now to get started."

## Common Mistakes

1. **No individual values** -- Listing components without dollar amounts reduces perceived value
2. **Unrealistic values** -- Inflated numbers that nobody believes ($100,000 value for a PDF)
3. **Too few components** -- A thin stack (2-3 items) does not create the value gap needed
4. **Revealing price first** -- Showing the price before building the stack kills the contrast
5. **Generic names** -- "Bonus 1" instead of "The Conversion Copywriting Swipe File"
6. **No guarantee** -- Missing the risk reversal that removes the final objection
7. **Rushing the build** -- Adding all components at once instead of building one at a time
