# SOP: Funnel Architecture Design

> Source: DotCom Secrets + Ignite | Version: 1.0 | Agent: brunson-funnels

---

## 1. Purpose
Select the right funnel type and design the complete page-by-page architecture for a specific Value Ladder entry point.

## 2. Pre-conditions
- [ ] Value Ladder completed
- [ ] Entry point (which tier) selected
- [ ] Offer for this funnel defined

## 3. Procedure

### Step 1: Select Funnel Type (15 min)
Based on the offer and price point, select from the 9 core funnels:

| Price Range | Funnel Type |
|-------------|-------------|
| Free (lead gen) | Squeeze Page, Survey, or Summit Funnel |
| $7-$97 | Book/Cart, Challenge, or Invisible Funnel |
| $297-$2,997 | Webinar, Product Launch, or Auto-Webinar Funnel |

### Step 2: Map the Page Flow (20 min)
List every page in the funnel in sequence:
1. Traffic source → [Pre-frame page if needed]
2. Landing/squeeze page
3. Thank you / confirmation page
4. Sales page (if applicable)
5. Order form page
6. OTO/upsell page(s)
7. Downsell page(s)
8. Thank you / delivery page

### Step 3: Apply 7 Phases (30 min)
Map each page to its phase:
1. Pre-Frame Bridge — How are visitors being set up?
2. Qualify Subscribers — How do we capture leads?
3. Qualify Buyers — How do we get the first sale?
4. Identify Hyperactive Buyers — Who buys everything?
5. Age & Ascend — How do we move them up the ladder?
6. Change Selling Environment — Webinar, phone call, event?
7. Monetize — What's the long-term value play?

### Step 4: Design Each Page (45 min)
For each page, define:
- Page type and layout
- Hook (headline)
- Core content / story
- Offer or CTA
- Key conversion elements

### Step 5: Design Follow-Up Sequences (30 min)
- Soap Opera Sequence (new subscribers)
- Buyer follow-up (new buyers)
- Non-buyer retargeting (didn't buy)
- Ascension sequence (move up the ladder)

### Step 6: Define KPIs (15 min)
Set benchmarks for each page:
- Opt-in rate target
- Sales page conversion target
- OTO take rate target
- Email open/click rate targets

## 4. Outputs
- [ ] Funnel type selection with justification
- [ ] Complete page flow diagram
- [ ] Page specs for each page
- [ ] Follow-up sequence outlines
- [ ] KPI targets

## 5. Quality Checks
- [ ] Funnel type matches offer price point
- [ ] Every page has one clear CTA
- [ ] Follow-up funnel is designed
- [ ] Hook-Story-Offer applied to each page
