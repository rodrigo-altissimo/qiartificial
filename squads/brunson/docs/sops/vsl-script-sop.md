# SOP: VSL (Video Sales Letter) Script

> Source: DotCom Secrets + Expert Secrets | Version: 1.0 | Agent: brunson-copy

---

## 1. Purpose
Write a complete VSL script that presents an offer through video, combining Hook-Story-Offer with visual storytelling.

## 2. Pre-conditions
- [ ] Offer with value stack
- [ ] Origin story written
- [ ] Target audience defined
- [ ] Testimonials available

## 3. Procedure

### Step 1: Write the Hook (First 30 Seconds) (15 min)
- Pattern interrupt statement
- Big promise
- Reason to keep watching
- "In the next [X] minutes, I'm going to show you..."

### Step 2: Build Credibility (30 Seconds) (10 min)
- Quick credentials (results, not resume)
- Social proof snippet
- "I've helped [X] people achieve [Y]"

### Step 3: Tell the Origin Story (3-5 Minutes) (30 min)
- Epiphany Bridge format
- Emotional and relatable
- Discovery of the solution
- Results achieved

### Step 4: Present the Opportunity (2-3 Minutes) (20 min)
- Frame as NEW opportunity (not improvement)
- Explain the mechanism (why it works)
- Address the Big Domino belief

### Step 5: Share Proof (2-3 Minutes) (15 min)
- Client testimonials (video clips if possible)
- Case studies with specific numbers
- Before/after stories

### Step 6: Present the Offer (3-5 Minutes) (20 min)
- "Here's what I've put together for you..."
- Present each component with value
- Build the stack
- Total value → price reveal
- Guarantee
- CTA

### Step 7: Handle Objections (2-3 Minutes) (15 min)
- "Now you might be thinking..."
- Address top 3 objections
- Turn each objection into a reason to buy

### Step 8: Final Close (1-2 Minutes) (10 min)
- Recap the transformation
- Urgency/scarcity
- "Click the button below"
- Two-path close

## 4. Outputs
- [ ] Complete VSL script (15-25 minutes)
- [ ] Slide notes or B-roll suggestions
- [ ] CTA overlay text

## 5. Quality Checks
- [ ] First 30 seconds hook attention
- [ ] Story creates emotional connection
- [ ] Offer is presented with full stack
- [ ] Objections are addressed
- [ ] Clear CTA at the end
- [ ] Total runtime 15-25 minutes
