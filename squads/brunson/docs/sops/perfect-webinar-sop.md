# SOP: Perfect Webinar Creation

> Source: Expert Secrets, Ch. 11-15 | Version: 1.0 | Agent: brunson-webinar

---

## 1. Purpose
Create a complete Perfect Webinar presentation that changes beliefs through stories and converts attendees into buyers using the Stack Slide.

## 2. Pre-conditions
- [ ] Offer defined with price point ($297-$2,997)
- [ ] Target audience identified
- [ ] Personal origin story available
- [ ] Client stories/results available

## 3. Procedure

### Step 1: Identify the Big Domino (20 min)
Write: "If I can make them believe that [NEW OPPORTUNITY] is the key to [DESIRE] and is only attainable through [MY VEHICLE], then all other objections disappear."

### Step 2: Map 3 False Beliefs (15 min)
- False Belief #1 (Vehicle): What do they believe about the opportunity?
- False Belief #2 (Internal): What do they believe about their ability?
- False Belief #3 (External): What do they believe about outside forces?

### Step 3: Craft 3 Epiphany Bridge Stories (60 min)
For each false belief, write an Epiphany Bridge story (8 steps):
Backstory → Desire → Wall → Epiphany → Plan → Conflict → Achievement → Transformation

### Step 4: Write the Introduction (15 min)
- Big promise (what they'll learn)
- Quick credibility
- 3 Secrets preview
- Permission to pitch

### Step 5: Write Each Secret Section (45 min)
For each of the 3 Secrets:
- Transition from previous section
- Teaching content (just enough)
- Epiphany Bridge story
- Belief reframe

### Step 6: Write the Transition to Offer (10 min)
- Recap what's now possible
- "Do you want my help?"
- Natural bridge to the Stack

### Step 7: Design the Stack Slide (20 min)
- List 5+ components with individual values
- Calculate total value
- Set price as fraction of total
- Design reveal sequence

### Step 8: Write the Close (20 min)
- Present each component one by one
- Build stack after each addition
- Reveal total → anchor → price
- Guarantee → urgency → CTA

## 4. Outputs
- [ ] Complete webinar script (60-90 min)
- [ ] Stack Slide design
- [ ] Slide outline (slide by slide)
- [ ] Registration page copy

## 5. Quality Checks
- [ ] Big Domino is specific and believable
- [ ] Each secret has an Epiphany Bridge story
- [ ] Stack has 5+ components
- [ ] Total value >= 3x price
- [ ] Guarantee included
