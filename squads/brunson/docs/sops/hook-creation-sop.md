# SOP: Hook Creation

> Source: Traffic Secrets + Expert Secrets | Version: 1.0 | Agent: brunson-hooks

---

## 1. Purpose
Create attention-capturing hooks for ads, emails, social posts, and funnel pages that stop the scroll and create curiosity.

## 2. Pre-conditions
- [ ] Target audience defined
- [ ] Core offer identified
- [ ] Key result/transformation known

## 3. Procedure

### Step 1: Identify the Core Promise (10 min)
What's the ONE result your audience most desires? Write it as: "[Avatar] wants to [result] without [pain]."

### Step 2: Generate Hooks by Type (45 min)
Create 5+ hooks per category:

**Curiosity**: "The weird trick that...", "What [expert] doesn't want you to know about..."
**Contrarian**: "Why [common belief] is actually destroying your..."
**Result**: "How [person] achieved [specific result] in [timeframe]"
**Story**: "The day I discovered...", "I almost quit until..."
**Pattern Interrupt**: "STOP scrolling if you're a [avatar]"
**Question**: "What if you could [desire] in just [time]?"
**Stat/Fact**: "[Number]% of [group] fail at [thing]. Here's why..."

### Step 3: Apply Hook to Context (20 min)
Adapt top hooks for each context:
- Ad headline (short, punchy)
- Email subject line (curiosity-driven)
- Social post first line (scroll-stopping)
- Page headline (benefit-focused)
- Video first 3 seconds (pattern interrupt)

### Step 4: Test and Rank (15 min)
- Select top 3 hooks per context
- Plan A/B tests
- Define winner criteria

## 4. Outputs
- [ ] 50+ hooks across all categories
- [ ] Top 3 hooks per context
- [ ] A/B test plan

## 5. Quality Checks
- [ ] Each hook creates curiosity or emotion
- [ ] Hooks are specific to the avatar
- [ ] Hooks promise a clear benefit
- [ ] Hooks work within 3 seconds
