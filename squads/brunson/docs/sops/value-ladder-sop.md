# SOP: Value Ladder Design

> Source: DotCom Secrets, Chapter 2 | Version: 1.0 | Agent: brunson-funnels

---

## 1. Purpose
Design a complete Value Ladder with 3-5 tiers that ascends customers from free to high-ticket while delivering increasing value at each step.

## 2. Pre-conditions
- [ ] Dream customer avatar defined (Secret Formula)
- [ ] Core offer or expertise identified
- [ ] Understanding of market price points

## 3. Procedure

### Step 1: Identify Your Core Offer (15 min)
What do you currently sell or plan to sell? This becomes your MIDDLE tier.
- Name the offer
- Define the price point
- Describe the transformation it delivers

### Step 2: Design the Bait / Lead Magnet (20 min)
Create the FREE entry point that attracts dream customers.
- Solve ONE specific problem related to the core offer
- Format: PDF, video, checklist, quiz, or challenge
- Must be genuinely valuable (not just a teaser)

### Step 3: Design the Frontend Offer (20 min)
Create the low-ticket offer ($7-$97) that converts leads to buyers.
- Solve the NEXT problem after the lead magnet
- Low risk, high perceived value
- Self-liquidating: covers ad spend

### Step 4: Design the Backend Offer (20 min)
Create the premium offer ($997-$9,997) above the core.
- Higher access, faster results, or done-with-you
- Natural next step for core offer graduates
- Smaller audience, higher value per person

### Step 5: Design Continuity / High-Ticket (15 min)
Create the top tier ($10K+) or continuity program.
- Ongoing relationship or done-for-you
- Highest value, smallest group
- May include 1-on-1 access

### Step 6: Map Ascension Triggers (20 min)
For each transition between tiers, define:
- What triggers the upgrade? (completion, results, time)
- What email/sequence drives the ascension?
- What's the natural "next problem" they face?

### Step 7: Validate Price-Value Alignment (15 min)
For each tier, verify:
- Value delivered >= 10x the price
- Price jump between tiers <= 5-10x
- Each tier has a clear, distinct transformation

## 4. Outputs
- [ ] Complete Value Ladder diagram (5 tiers)
- [ ] Offer description per tier
- [ ] Ascension trigger map
- [ ] Price-value alignment validation

## 5. Quality Checks
- [ ] Minimum 3 tiers defined
- [ ] Each tier has a distinct transformation
- [ ] Ascension path is logical
- [ ] No gap > 10x price jump between adjacent tiers
