# SOP: Sales Page Creation

> Source: DotCom Secrets + Expert Secrets | Version: 1.0 | Agent: brunson-pages

---

## 1. Purpose
Design and write a complete sales page following Hook-Story-Offer structure that converts visitors into buyers.

## 2. Pre-conditions
- [ ] Offer with value stack defined
- [ ] Target audience avatar
- [ ] Epiphany Bridge origin story
- [ ] Testimonials/proof elements

## 3. Procedure

### Step 1: Write the Hook Section (20 min)
- Pre-headline (calls out avatar): "[Avatar], are you tired of [pain]?"
- Main headline: "How to [Result] in [Time] Without [Pain]"
- Sub-headline: Amplifies or adds specificity
- Hero image or video (optional)

### Step 2: Write the Story Section (30 min)
- Origin story using Epiphany Bridge
- Relatable backstory
- The epiphany moment
- How the solution was born
- Results achieved

### Step 3: Write the Offer Section (30 min)
- Transition: "Here's what I've put together for you..."
- Present each stack component individually
- Build value as you go
- Total value reveal → price reveal

### Step 4: Write the Proof Section (20 min)
- Testimonials with specific results
- Case studies (before/after)
- Media mentions or credentials
- Numbers and statistics

### Step 5: Write the Guarantee Section (10 min)
- Clear guarantee statement
- Duration and conditions
- Make it feel risk-free

### Step 6: Write the Scarcity/Urgency Section (10 min)
- Genuine scarcity or urgency
- Deadline, limited spots, or bonus expiration
- Reason WHY it's limited

### Step 7: Write the Close Section (15 min)
- Final CTA with benefit-oriented button text
- Two-path close: "You have two choices..."
- P.S. (recap the guarantee and urgency)

### Step 8: Write the FAQ Section (15 min)
- Address top 5-7 objections as questions
- Each answer reinforces value

## 4. Outputs
- [ ] Complete sales page copy
- [ ] Wireframe layout
- [ ] CTA button text options

## 5. Quality Checks
- [ ] Hook stops the scroll
- [ ] Story builds emotional connection
- [ ] Offer feels irresistible
- [ ] Proof elements are specific
- [ ] Guarantee reverses risk
- [ ] One clear CTA (no competing actions)
