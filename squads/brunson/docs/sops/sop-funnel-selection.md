# SOP: Funnel Selection

## Purpose

Select the optimal funnel type for a specific offer based on price point, traffic temperature, audience sophistication, and business objectives. Prevent the costly mistake of using the wrong funnel architecture for the situation.

---

## Prerequisites

- Completed Value Ladder with at least one defined offer
- Clear offer details: price, format, delivery method, target customer
- Understanding of current traffic sources and their temperature (cold/warm/hot)
- Knowledge of the Nine Core Funnels framework

---

## Step-by-Step Procedure

### Step 1: Classify Your Offer (15 min)

1. Determine the price point of the offer being sold
2. Classify into tier:
   - **Frontend:** $0-100 --> Funnels 1-3
   - **Middle:** $100-10,000 --> Funnels 4-6
   - **Backend:** $10,000+ --> Funnels 7-9
3. Note the offer format (digital, physical, service, membership, coaching)

### Step 2: Assess Traffic Temperature (15 min)

Rate your primary traffic source:

| Temperature | Description | Funnel Implication |
|------------|-------------|-------------------|
| Cold | Never heard of you | Needs more trust-building pages, longer sequences |
| Warm | Knows you but has not bought | Can use shorter funnels, moderate trust building |
| Hot | Existing customer or avid follower | Can go direct to offer with minimal warm-up |

### Step 3: Evaluate Business Context (15 min)

Answer these questions:
1. Is this a new offer or an established one?
2. Do you have an existing email list? How large?
3. What is your ad budget for the launch?
4. Do you have sales staff for phone closes?
5. What is your timeline to launch?
6. Do you have video/presentation skills or prefer written?

### Step 4: Match to Funnel Type (30 min)

Use this decision matrix:

**If price is $0-50 + physical product:** Free + Shipping Funnel
**If price is $27-97 + digital product:** SLO Funnel
**If recurring monthly charge:** Continuity/Membership Funnel
**If price is $297-2,000 + you can present live/recorded:** Perfect Webinar Funnel
**If cold audience + need to build trust first:** Invisible Funnel
**If new product + you have an email list:** Product Launch Funnel
**If price is $3,000+ + requires qualification:** Application Funnel
**If want to build authority + partnerships rapidly:** Summit/Event Funnel
**If want engaged community + $497-2,997 offer:** Challenge Funnel

### Step 5: Validate the Selection (15 min)

Run these validation checks:
1. Find 3-5 competitors using this funnel type successfully
2. Confirm you have the resources to build it (tech, content, team)
3. Verify the timeline is realistic for this funnel complexity
4. Check that your traffic source can support this funnel type

### Step 6: Define the Minimum Viable Funnel (30 min)

Strip the funnel to its essential pages:
1. List every page in the funnel (minimum required)
2. Identify which pages to build first vs. add later
3. Define the core email sequences needed
4. Set the launch date for the MVP version

---

## Quality Checks

- [ ] Funnel type matches offer price point and tier
- [ ] Traffic temperature has been assessed and accommodated
- [ ] At least 3 competitor examples of this funnel type found
- [ ] Resources (budget, skills, time) confirmed for this funnel type
- [ ] MVP page list defined with realistic timeline
- [ ] Email sequences identified (pre-funnel, in-funnel, post-funnel)

---

## Handoff

Deliver to the team:
1. **Funnel Selection Brief** -- Which funnel type and why
2. **Competitor Examples** -- 3-5 links to similar funnels for reference
3. **MVP Page List** -- Minimum pages needed to launch
4. **Timeline** -- Build and launch schedule
5. **Next Action** -- First page or asset to create

---

*Estimated Time: 2 hours*
*Review Cycle: Per new offer launch*
