# SOP: Funnel Audit & Optimization

> Source: DotCom Secrets + Funnel Hacking | Version: 1.0 | Agent: brunson-advisor

---

## 1. Purpose
Diagnose an underperforming funnel, identify the #1 bottleneck, and create a prioritized fix plan.

## 2. Pre-conditions
- [ ] Existing funnel with traffic
- [ ] Access to analytics
- [ ] Conversion data at each step

## 3. Procedure

### Step 1: Collect Metrics (20 min)
For each funnel page, record: traffic volume, conversion rate, bounce rate, time on page.
For email: open rate, click rate, unsubscribe rate.
Overall: EPC (earnings per click), CPA (cost per acquisition), ROAS.

### Step 2: Map Current Funnel (15 min)
Document every page, email, and offer in the exact order a customer experiences them.

### Step 3: Apply 100-Visitors Test (15 min)
For each page, ask: "If 100 people land here, how many convert?" Compare against benchmarks:
- Squeeze page: >25%
- Sales page: >2%
- OTO page: >10%
- Webinar registration: >25%

### Step 4: Audit Hook-Story-Offer Per Page (30 min)
Score each page 1-10 on:
- Hook (does the headline capture attention?)
- Story (does it build belief?)
- Offer (is it irresistible?)

### Step 5: Identify the #1 Bottleneck (10 min)
Find the single weakest link. Fix this FIRST for the biggest impact.

### Step 6: Create Fix Recommendations (30 min)
For top 3 issues:
- What to change
- Why it matters (data)
- How to implement
- Expected impact
- Timeline

### Step 7: Design A/B Tests (15 min)
For each fix, define: control, variant, sample size, duration, success criteria.

## 4. Outputs
- [ ] Audit metrics spreadsheet
- [ ] Bottleneck analysis
- [ ] Prioritized fix list
- [ ] A/B test plans
- [ ] Executive summary

## 5. Quality Checks
- [ ] All metrics collected
- [ ] #1 bottleneck identified with data
- [ ] Fixes are specific and actionable
- [ ] A/B tests are properly designed
