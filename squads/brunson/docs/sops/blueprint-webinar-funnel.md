# Blueprint: Webinar Funnel

## Overview

The Webinar Funnel is the primary engine for selling $297-$2,000 offers using the Perfect Webinar framework. It drives traffic to a registration page, nurtures registrants with pre-webinar emails, delivers a 60-90 minute presentation that builds belief and breaks false beliefs, then closes with a stacked offer. This is the most battle-tested funnel in the Brunson ecosystem for middle-tier offers.

## Components

### Registration Page
- Headline: "How to [result] without [fear]" + date/time
- Bullet points: 3 things they will learn
- Urgency: "Limited seats" or specific date
- Registration form: name + email
- Countdown timer to event

### Pre-Webinar Email Sequence (3-5 emails)
- Confirmation email with calendar link (immediate)
- "What to expect" email (Day -2)
- Story-based anticipation builder (Day -1)
- Day-of reminder (morning of webinar)
- "Starting now" notification (15 min before)

### Webinar Presentation (Perfect Webinar Format)
- Introduction: Hook + Rapport + Origin Story (10 min)
- Secret 1: Vehicle belief break (15 min)
- Secret 2: Internal belief break (15 min)
- Secret 3: External belief break (15 min)
- Stack + Close: Offer presentation (25 min)
- Q&A: Objection handling (10 min)

### Sales Page
- Available during and after the webinar
- Mirrors the webinar content in written form
- Full stack section with values
- Testimonials and social proof
- Guarantee and urgency

### Post-Webinar Follow-Up
- Replay email (available 24-72 hours)
- Testimonial emails (Days 1-3)
- Objection-handling emails (Days 2-4)
- Cart close email sequence (Day 5-7)
- No-show sequence (condensed version of the webinar pitch)

## Implementation Steps

1. Write the Big Domino Statement for your offer
2. Script the full Perfect Webinar (Introduction + 3 Secrets + Stack/Close)
3. Create the slide deck (60-120 slides)
4. Build the registration page with countdown
5. Build the sales page with full stack section
6. Configure the webinar platform (live or automated)
7. Write all email sequences (pre-webinar, post-webinar, no-show)
8. Create the order form with order bump and upsell
9. Set up the replay page with expiration timer
10. Rehearse the webinar minimum 3 times
11. Launch with traffic to registration page
12. Run the webinar and track all metrics

## Metrics

| Metric | Target | How to Measure |
|--------|--------|----------------|
| Registration Rate | 20-35% | Registrants / Page visitors |
| Show-Up Rate | 25-40% | Attendees / Registrants |
| Stay Rate | 50-70% | Stayed to offer / Attendees |
| Offer Conversion | 5-15% | Buyers / Attendees |
| Replay Conversion | 2-5% | Buyers from replay / Replay viewers |
| No-Show Recovery | 1-3% | No-show buyers / No-shows |
| Earnings Per Registrant | $5-$20 | Total revenue / Total registrants |
| Cost Per Registration | $3-$15 | Ad spend / Registrants |

**Goal:** Earnings Per Registrant must exceed Cost Per Registration for the funnel to be profitable.
