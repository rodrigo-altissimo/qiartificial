# SOP: Funnel Page Design

## Purpose

Design and build the core pages of a sales funnel following Brunson's proven page structures. This SOP covers squeeze pages, sales pages, order forms, upsell pages, and thank-you pages with copy frameworks, layout principles, and conversion optimization guidelines.

---

## Prerequisites

- Funnel type selected (from Funnel Selection SOP)
- Offer and Stack defined (from Offer Stacking SOP)
- Hook library created (from Hook Creation SOP)
- Lead magnet or core offer finalized
- Funnel building tool access (ClickFunnels, WordPress, or equivalent)
- Brand assets: logo, colors, fonts, images

---

## Step-by-Step Procedure

### Step 1: Map the Page Flow (30 min)

1. List every page in the funnel in order:
   - Squeeze/Opt-in Page
   - Thank You / Bridge Page
   - Sales Page or Webinar Registration
   - Order Form
   - OTO (One Time Offer) Upsell Page(s)
   - Downsell Page (if applicable)
   - Confirmation / Thank You Page
2. Define the goal of each page (one action per page)
3. Sketch wireframes for each page (hand-drawn or digital)

### Step 2: Build the Squeeze Page (1 hour)

**Required Elements:**
1. **Headline:** Hook that promises a specific result
2. **Sub-headline:** Clarify what they get and how fast
3. **Bullet points (3-5):** Specific benefits of the lead magnet
4. **Image/Mockup:** Visual of what they will receive
5. **Opt-in Form:** Name + email (keep fields minimal)
6. **CTA Button:** Action-oriented text ("Get My Free Guide" not "Submit")
7. **Social Proof:** Testimonial or subscriber count (optional but helpful)

**Design Rules:** No navigation menu, no footer links, no distractions. ONE action only: opt in.

### Step 3: Build the Sales Page (2-3 hours)

Follow the Hook-Story-Offer structure:

**Above the Fold:**
- Headline (hook)
- Sub-headline (clarify the promise)
- Video or hero image
- CTA button (even before they scroll)

**Story Section:**
- Problem agitation (describe their pain)
- Your Epiphany Bridge story (abbreviated)
- The solution introduced

**Offer Section:**
- What they get (Stack format)
- Each component with name, description, value
- Total value displayed prominently
- Price reveal with contrast to total value
- Guarantee
- CTA button

**Proof Section:**
- Testimonials (video preferred, text acceptable)
- Case studies with specific results
- Authority markers (media mentions, certifications, numbers)

**FAQ Section:**
- 5-10 common objections answered
- Each FAQ subtly reinforces the offer value

**Final CTA:**
- Urgency reminder
- Last CTA button
- P.S. section summarizing the key benefit and deadline

### Step 4: Build the Order Form (30 min)

1. Summarize the offer at the top of the form
2. Include an order bump checkbox (small add-on, $27-97)
3. Minimal form fields: name, email, payment info
4. Trust badges: secure checkout, guarantee reminder
5. CTA button text: "Complete My Order" or similar

### Step 5: Build Upsell/OTO Pages (1 hour)

For each upsell (typically 1-3):
1. **Headline:** "Wait! Your order is not complete..."
2. **Video or text:** Short pitch for the complementary offer
3. **What they get:** Brief stack or bullet points
4. **Price:** Usually 30-50% of the core offer price
5. **Two buttons:** "Yes, add this to my order" and "No thanks, skip this"
6. No long sales pages -- upsells should convert in 2-3 minutes

### Step 6: Build Confirmation Page (30 min)

1. Confirm their purchase with enthusiasm
2. Set expectations: what happens next (login, email, shipping)
3. Optional: introduce the next step on the Value Ladder (soft)
4. Encourage them to join the community (if applicable)

### Step 7: Mobile Optimization (1 hour)

1. Test every page on mobile devices
2. Ensure CTA buttons are thumb-friendly and above the fold
3. Optimize image sizes for fast loading
4. Simplify layouts for vertical scrolling
5. Test the full funnel flow on mobile end-to-end

---

## Quality Checks

- [ ] Every page has ONE clear action (no competing CTAs)
- [ ] No navigation menus or external links on sales pages
- [ ] Headline follows Hook framework (specific, curiosity, relevant)
- [ ] Stack section shows total value vs. price with 10x+ gap
- [ ] Guarantee is visible and specific
- [ ] Order form has an order bump
- [ ] At least one upsell page configured
- [ ] All pages tested on mobile
- [ ] Page load time under 3 seconds
- [ ] All links and buttons functional end-to-end

---

## Handoff

Deliver:
1. **Live Funnel URL** -- All pages built and connected
2. **Page Flow Map** -- Visual diagram of the complete funnel
3. **Copy Document** -- All page copy in a single reference document
4. **Mobile Screenshots** -- Confirmation of mobile optimization
5. **Test Results** -- End-to-end test completion confirmation

*Estimated Time: 8-12 hours for a complete funnel*
*Review Cycle: Weekly during launch, monthly ongoing*
