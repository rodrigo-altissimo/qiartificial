# SOP: Offer Stacking

## Purpose

Design and build a value-stacked offer that creates a massive perceived value gap between the total worth and the actual price. The Stack makes saying "no" feel irrational by demonstrating that the buyer receives 10x+ more value than they pay. This SOP covers component selection, value assignment, visual presentation, and testing.

---

## Prerequisites

- Core product or service defined with clear deliverables
- Target price point established
- Understanding of the dream customer's biggest desires and objections
- Competitor offer research completed
- Access to the Stack Slide framework documentation

---

## Step-by-Step Procedure

### Step 1: Define the Core Offer (30 min)

1. Name the core product with a compelling, benefit-oriented title
2. List the specific deliverables (modules, features, sessions, etc.)
3. Define the transformation this core offer provides
4. Assign a standalone value (what would someone pay for this alone?)
5. This value becomes the anchor at the top of the stack

### Step 2: Identify Gaps and Objections (30 min)

1. List 5-10 objections the buyer might have AFTER believing in the core offer
2. Common objection categories:
   - "I do not know HOW to implement this"
   - "I do not have time to figure this out on my own"
   - "What if it does not work for MY situation?"
   - "I need support and accountability"
   - "I need templates/tools to make this easier"
3. Each objection becomes a potential bonus component

### Step 3: Design Bonus Components (1 hour)

For each major objection, create a bonus that eliminates it:

**Implementation Tools:**
- Templates, swipe files, scripts, checklists, spreadsheets
- Value: what would someone pay a freelancer to create these?

**Speed Accelerators:**
- Quick-start guide, 30-day plan, fast-action blueprint
- Value: what is the cost of doing this slowly (lost revenue, time)?

**Support Access:**
- Community membership, Q&A calls, office hours, coaching
- Value: what does comparable coaching cost per hour x hours?

**Done-For-You Elements:**
- Audits, reviews, setup assistance, customization
- Value: what would a consultant charge for this service?

**Exclusive Content:**
- Advanced training, masterclass, interview series, case studies
- Value: what do similar standalone trainings sell for?

### Step 4: Assign Values (30 min)

For each component:
1. Research what similar items sell for in the market
2. Assign a specific dollar value (not a range)
3. Ensure each value is defensible (could you actually sell it at that price?)
4. Avoid absurd values that destroy credibility ($50,000 for a PDF)
5. Calculate running total -- aim for 10x+ the actual price

### Step 5: Order the Stack (15 min)

1. Place the core offer at the top (highest individual value)
2. Add implementation tools next
3. Add speed accelerators
4. Add support/community access
5. Add exclusive bonuses last (these create urgency)
6. Mark which bonuses are available only for fast action takers

### Step 6: Build the Stack Visual (1 hour)

1. Create the Stack Slide for webinar use
2. Create the sales page version (scrolling stack section)
3. Each component gets: Name, Description (1 sentence), Value
4. Running total visible and growing with each addition
5. Price reveal at the bottom with clear contrast to total value
6. Guarantee positioned directly after the price

### Step 7: Add Urgency Layers (30 min)

1. Identify 1-2 bonuses that are genuinely limited (time, quantity, or availability)
2. Add a deadline or scarcity element tied to these bonuses
3. Write the urgency copy: "This bonus is only available until [date]..."
4. Ensure urgency is real -- fake scarcity destroys trust permanently

---

## Quality Checks

- [ ] Core offer is named and valued
- [ ] Minimum 4-6 bonus components in the stack
- [ ] Each component has a specific, defensible dollar value
- [ ] Total stacked value is 10x+ the actual price
- [ ] Each bonus addresses a specific objection or gap
- [ ] Components ordered from highest to lowest value
- [ ] Stack Slide visual created for webinar use
- [ ] Sales page stack section created
- [ ] Urgency element is real and compelling
- [ ] Guarantee is specific and bold
- [ ] Payment plan option available for higher price points

---

## Handoff

Deliver:
1. **Stack Component Document** -- All components with names, descriptions, and values
2. **Stack Slide** -- Visual for webinar presentation
3. **Sales Page Stack Section** -- Copy and layout for the sales page
4. **Urgency Plan** -- Which bonuses are limited and the deadlines
5. **Guarantee Copy** -- The specific guarantee language
6. **Competitor Comparison** -- How your stack compares to competitors' offers

---

*Estimated Time: 4-5 hours*
*Review Cycle: Per offer launch and quarterly for existing offers*
