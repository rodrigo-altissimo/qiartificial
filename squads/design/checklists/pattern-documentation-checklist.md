# Pattern Documentation Checklist

## 1. Overview

- [ ] Describes what the pattern is and its primary purpose.
- [ ] Provides clear examples of when to use it (and when not to use it).

## 2. Anatomy & Behavior

- [ ] Includes visual examples or diagrams.
- [ ] Details interaction states (hover, active, focused).

## 3. Implementation

- [ ] Contains code snippets or sandbox links.
- [ ] References related guidelines (accessibility, content).
