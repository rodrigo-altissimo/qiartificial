# Design System ROI Checklist

## Pass Criteria
- **Threshold:** Score >= 5/7 = PASS
- **Veto:** Cost savings must be calculated.

## 1. Metrics Baseline (Weight: 2)

- [ ] Time-to-market metrics established for new features.
  - *If FAIL -> Track Jira/Linear cycle times for features using DS vs not.*
- [ ] Average QA/Accessibility bugs per release measured.
  - *If FAIL -> Pull bug reports from the last 3 releases to form a baseline.*

## 2. Value Measurement (Weight: 3)

- [ ] Component usage times tracked.
  - *If FAIL -> Implement Figma analytics or code-scanning for component instances.*
- [ ] Onboarding time for new team members measured.
  - *If FAIL -> Survey recent hires on time-to-first-commit.*
- [ ] Cost savings calculated based on reduced redundant work.
  - *If FAIL -> Multiply (Hours saved per component) x (Average Dev Hourly Rate).*

## 3. Reporting (Weight: 2)

- [ ] ROI report generated quarterly.
  - *If FAIL -> Set calendar reminder to aggregate data every 3 months.*
- [ ] Stakeholder review scheduled.
  - *If FAIL -> Book a 15-minute slot in the Engineering All-Hands.*
